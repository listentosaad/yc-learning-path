# مسار المؤسس

</p>

مسار دراسي منظّم لإتقان أساسيات بناء الشركات الناشئة، يجمع أفضل محتوى **Y Combinator** (فيديوهات ومقالات بول غراهام) في ٦ وحدات مرتّبة، مع تتبّع تقدّم محفوظ تلقائيًا في متصفحك.

**🔗 جرّب المسار مباشرة:** [founder-path.com](https://founder-path.com)

## المحتوى

المسار مقسّم إلى ٦ وحدات، كل وحدة فيها فيديوهات وقراءات:

| # | الوحدة | الموضوع |
|---|---|---|
| ٠١ | القرار بالبدء | هل يجب أن تبني شركة ناشئة؟ |
| ٠٢ | الفكرة وتقييمها | كيف تجد فكرة تستحق البناء |
| ٠٣ | بناء الفريق المؤسس | الشركاء والحصص والديناميكية |
| ٠٤ | التخطيط للـ MVP | من الفكرة إلى أول نسخة قابلة للاختبار |
| ٠٥ | الإطلاق | كيف تخرج للسوق وتكسب أول عملائك |
| ٠٦ | النمو وتحديد المؤشرات | المؤشرات والتسعير واستراتيجيات النمو |

كل عنصر (فيديو 📺 أو قراءة 📖) قابل للتحديد كمكتمل، والتقدّم يُحفظ محليًا في المتصفح (`localStorage`) — بدون تسجيل دخول أو حساب.

## البنية التقنية

- **React 18** + **Vite** — تطبيق صفحة واحدة (SPA)
- **Tailwind CSS** — التنسيق
- خط Thmanyah (Sans + Serif) مضمّن في `public/fonts`

المشروع بالكامل ملف واحد أساسي: `src/App.jsx` — قائمة الوحدات معرّفة كمصفوفة بيانات ثابتة في أعلى الملف، فإضافة وحدة أو درس جديد يعني تعديل تلك المصفوفة فقط.

## التشغيل محليًا

```bash
npm install
npm run dev      # تشغيل محلي
npm run build    # بناء للإنتاج
npm run preview  # معاينة نسخة الإنتاج
```
